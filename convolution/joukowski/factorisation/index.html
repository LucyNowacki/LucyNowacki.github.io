What each operator does

01 · RESTRICT THE INPUT

Keep the function, narrow its domain

\[g=\mathcal J_2f=f|_{E_s}.\]

The strict gap between \(E_s\) and \(E_r\) lets Hardy control on the larger ellipse bound every value on the smaller one.

Intuitive/geometric explanation

Imagine looking at the same analytic function through a smaller window. No point is transported and no new function values are invented. The input hump records angular mean-square size on \(E_r\); the inner lighthouse measures the modulus of its restriction on \(E_s\).

02 · FORM THE RESPONSE

Look inward to compute an outer value

\[h(\omega)=\sum_b\phi_b(\omega)g(\tau_b(\omega)).\]

Choose an outer point \(\omega\). Its inverse-branch images lie inside \(E_s\), where \(g\) is available. Add the weighted complex values there to obtain \(h(\omega)\).

Intuitive/geometric explanation

The solid arrows answer “where do we evaluate?” They point inward. The dashed middle arrow answers “which function do we construct?” It produces the response on the outer ellipse. Add the complex contributions before taking a magnitude.

\[h(\omega)=\tfrac12g(\tau_-(\omega))+\tfrac12g(\tau_+(\omega)).\]

The separate inner lighthouse is a moving probe on the boundary of \(E_s\); it is generally different from both branch-image points.

03 · RESTRICT THE OUTPUT

Return to the original measuring space

\[\mathcal Lf=\mathcal J_\infty h=h|_{E_r}.\]

The new response is now considered on the middle ellipse. Its second Hardy hump uses the same angular measure as the input hump.

Intuitive/geometric explanation

The two Hardy humps stand on the same ellipse but measure different functions: \(f\) and \(\mathcal Lf\). Restriction does not carry an outer point's value inward. The output value is evaluated anew at the middle-ellipse probe.

General mechanism, example and numerical meaning

For the general mechanism, assume finitely many branches \(\tau_b\) and weights \(\phi_b\), holomorphic near \(\overline{E_\rho}\), with \(\tau_b(\overline{E_\rho})\subset E_s\). Here \(A(E_\rho)=\operatorname{Hol}(E_\rho)\cap C(\overline{E_\rho})\). These conditions make the middle operation a bounded map into \(A(E_\rho)\).

The diagram uses the affine example above and the unnormalised Legendre polynomial input \(AP_n\). It illustrates the fixed-space factorisation and the two Hardy embeddings studied after the coefficient bounds. Both embeddings are restrictions; they are not inverses of one another.

The two humps use \(d t/(2\pi)\), not arclength. Their values are energies; take square roots to obtain Hardy norms. Supremum measurements take a maximum, with no integration. The displayed averages and maxima use 4,096 angular samples, evaluated in floating-point arithmetic without a certified error enclosure.
